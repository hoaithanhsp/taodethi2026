### PHẦN 1: NGUYÊN NHÂN GỐC RỄ CÁC LỖI

#### 🔴 Lỗi 1: Xuất file đề thi bị dính chùm một dòng (như Ảnh 1)
Nhìn vào Ảnh 1, toàn bộ câu hỏi, đáp án, dấu sao `*`, công thức `$`:
`2; 5]$. * B. $[1; 7)$. * C. $(2; 5)$. * D. $[1; 2]$. * *Đáp án:* A. ... * **Câu I.10...** * *Đề:* ... * A. 2. * B. 4.`
đều bị dồn vào **một khối văn bản duy nhất không có ngắt dòng**.

- **Vị trí lỗi:** Hàm `handleDownloadWord` trong `App.tsx` (dòng 672–711).
- **Cơ chế gây lỗi:**
  ```typescript
  // App.tsx dòng 696
  let sourceHTML: string;
  if (content.includes('<!DOCTYPE html>')) {
    sourceHTML = content.replace(...);
  } else {
    sourceHTML = header + content + footer; // 💥 LỖI TẠI ĐÂY!
  }
  ```
  Khi Gemini trả về nội dung đề thi dạng **Markdown** (chứa `\n`, `**`, `*`, `$`), `content.includes('<!DOCTYPE html>')` là `false`. Code nhảy vào nhánh `else` và **nhét thẳng chuỗi Markdown thô vào giữa `<body>` và `</body>`** của tài liệu HTML rồi gọi `asBlob` (html-docx-js) để tạo file `.docx`.
  
  Theo quy chuẩn HTML/Word: **Mọi ký tự xuống dòng `\n` trong text thuần đều bị co thành một khoảng trắng (single space)**. Vì không được chuyển đổi Markdown sang các thẻ `<p>`, `<br>`, `<div>`, Word hiển thị toàn bộ đề thi thành **một đoạn văn duy nhất dài vô tận**.

- **Điều nghịch lý:** Trong thư mục `services/` của dự án đã có sẵn file `exportUtils.ts` (dùng thư viện `markdown-it` để parse Markdown sang HTML có `breaks: true`), nhưng trong `App.tsx` lại không dùng đến!

#### 🔴 Lỗi 2: Ma trận, Đặc tả và Đề thi không theo đúng cấu trúc đã khai báo (Ảnh 2)

Trên Ảnh 2, bạn cấu hình:
- **Dạng I (4 lựa chọn):** Biết: 8, Hiểu: 4, VD: 0, VDC: 0 *(Tổng: 12 câu)*
- **Dạng II (Đúng/Sai):** Biết: 1, Hiểu: 1, VD: 0, VDC: 0 *(Tổng: 2 câu)*
- **Dạng III (Trả lời ngắn):** Biết: 1, Hiểu: 1, VD: 2, VDC: 0 *(Tổng: 4 câu)*
- **Tự luận:** Biết: 0, Hiểu: 0, VD: 0, VDC: 0 *(Tổng: 0 câu)*

Tuy nhiên, hệ thống bị lệch cấu trúc nghiêm trọng qua 3 bước do 2 lỗi logic sau:

##### 1. Xung đột giữa "Số Câu" và "Số Ý" ở Dạng II (Đúng/Sai):
- Theo quy định chuẩn của Bộ GD&ĐT (CV 7991 / GDPT 2018): Một câu hỏi Dạng II gồm **4 ý lệnh hỏi độc lập (a, b, c, d)**.
- Khi người dùng nhập `Biết: 1, Hiểu: 1`, người dùng đang muốn **2 CÂU Đúng/Sai** (mỗi câu 4 ý).
- Nhưng trong `services/geminiService.ts`:
  - **Ở Step 1 & Step 2 (Ma trận & Đặc tả - dòng 563 & 730):** Prompt lại ghi:
    `| Dạng II (Đúng-Sai) (ý) | 1 | 1 | 0 | 2 |`
    AI hiểu là cả đề chỉ có **2 Ý LỆNH HỎI** (tức chỉ nửa câu Đúng/Sai).
  - **Ở Step 3 (Đề thi - dòng 942 & 963):** Code lại tính:
    `counts.type2 = 1 + 1 = 2 câu`
    `- **PHẦN II (Đúng/Sai):** Tạo 2 câu hỏi (mỗi câu 4 ý a,b,c,d)`
    AI tạo ra **2 CÂU = 8 Ý HỎI**!
  - **Kết quả:** Đề thi có 2 câu (8 ý a,b,c,d), trong khi Ma trận và Đặc tả chỉ phân bổ 2 ý. Cả 3 bước mâu thuẫn hoàn toàn với nhau.

##### 2. Lỗi tự động ép sinh Tự Luận dù cấu hình = 0:
- Trong `App.tsx` (dòng 565–578), có đoạn code kiểm tra:
  ```typescript

  const specsHasEssay = detectEssayInHtml(genState.specs);

  if (totalEssay === 0) {
  ```

- Hàm `detectEssayInHtml` (dòng 265) chỉ kiểm tra đơn giản `html.toLowerCase().includes('tự luận')`.
- Khi AI tạo Ma trận hoặc Đặc tả, AI thường thêm ghi chú: *"Lưu ý: Đề thi không có phần tự luận"* hoặc *"Tự luận: 0 câu"*. Vì có xuất hiện chữ "tự luận", hàm này trả về `true`!

#### 🛠️ 1. Sửa lỗi xuất file Word trong `App.tsx`
Thay vì nhét chuỗi Markdown thô vào tài liệu HTML, hãy import và dùng hàm `exportToDoc` có sẵn từ `services/exportUtils.ts` (hoặc chuyển đổi qua `markdown-it` trước khi đóng gói `.docx`):

Mở `App.tsx`, thay thế hàm `handleDownloadWord` (khoảng dòng 672):

```typescript
// App.tsx
import { exportToDoc } from './services/exportUtils';
import MarkdownIt from 'markdown-it';

const mdParser = new MarkdownIt({
  html: true,
  breaks: true, // Bắt buộc: chuyển ký tự xuống dòng thành thẻ <br>
  linkify: true
});

const handleDownloadWord = async (content: string, fileName: string) => {
  try {
    let sourceHTML = '';

    // Nếu đã là Full HTML document (có thẻ html/body)
    if (content.includes('<!DOCTYPE html>') || (content.includes('<html') && content.includes('<body'))) {
      sourceHTML = content.replace(
        /<\/style>/i,
        `
          table { page-break-inside: auto; border-collapse: collapse; width: 100%; }
          tr { page-break-inside: avoid; }
          td, th { border: 1px solid black; padding: 5px; }
          p { margin-top: 4pt; margin-bottom: 4pt; line-height: 1.4; }
          .options { margin-left: 15pt; }
          .question-number { font-weight: bold; }
        </style>`
      );
    } else {
      // Nếu là MARKDOWN: Bắt buộc render sang HTML trước
      const renderedBody = mdParser.render(content);
      
      sourceHTML = `
        <!DOCTYPE html>
        <html lang="vi">
        <head>
          <meta charset="utf-8">
          <style>
            body { font-family: 'Times New Roman', serif; font-size: 13pt; line-height: 1.5; color: #000; }
            h1, h2, h3, h4 { font-weight: bold; margin-top: 10pt; margin-bottom: 6pt; }
            p { margin-top: 4pt; margin-bottom: 4pt; text-align: justify; }
            ul, ol { margin-top: 2pt; margin-bottom: 6pt; padding-left: 20pt; }
            li { margin-bottom: 3pt; }
            table { border-collapse: collapse; width: 100%; margin: 8pt 0; }
            td, th { border: 1px solid black; padding: 4pt 6pt; }
            th { background-color: #f2f2f2; font-weight: bold; }
            strong { font-weight: bold; }
          </style>
        </head>
        <body>
          ${renderedBody}
        </body>
        </html>
      `;
    }

    const blob = await asBlob(sourceHTML, {
      orientation: 'portrait',
      margins: { top: 720, right: 720, bottom: 720, left: 720 }
    });

    const url = URL.createObjectURL(blob as Blob);
    const link = document.createElement('a');
    link.href = url;
    link.download = `${fileName}.docx`;
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
    URL.revokeObjectURL(url);
  } catch (error) {
    console.error('Lỗi xuất file Word:', error);
    // Fallback: xuất file .doc text html
    const blob = new Blob(['\ufeff', content], { type: 'application/msword' });
    const url = URL.createObjectURL(blob);
    const link = document.createElement('a');
    link.href = url;
    link.download = `${fileName}.doc`;
    link.click();
    URL.revokeObjectURL(url);
  }
};
```

#### 🛠️ 2. Xóa bỏ logic tự ý bật Tự Luận trong `App.tsx`

```typescript
// App.tsx - Sửa lại hàm handleGenerateExam
const handleGenerateExam = async () => {
  if (!checkAuthOrTrial()) return;

  setGenState(prev => ({ ...prev, isLoading: true, error: null }));
  try {
    // TÔN TRỌNG CẤU HÌNH NGƯỜI DÙNG: Chỉ sinh tự luận nếu người dùng thực sự cài > 0
    const finalQuestionConfig = { ...inputData.questionConfig };
    
    // Nếu tổng câu tự luận người dùng cài = 0 thì chắc chắn essay = 0, không auto-set
    const userTotalEssay = 
      finalQuestionConfig.essay.biet + 
      finalQuestionConfig.essay.hieu + 
      finalQuestionConfig.essay.van_dung + 
      finalQuestionConfig.essay.van_dung_cao;

    if (userTotalEssay === 0) {
      finalQuestionConfig.essay = { biet: 0, hieu: 0, van_dung: 0, van_dung_cao: 0 };
    }

    // Auto-extract questions from reference doc if needed...
    let questionsToUse = extractedQuestions;
    if (referenceDoc && extractedQuestions.length === 0) {
      try {
        const extracted = await extractQuestionsFromReference(
          referenceDoc.text,
          referenceDoc.images,
          genState.specs,
          inputData.subject,
          inputData.grade
        );
        if (extracted.length > 0) {
          setExtractedQuestions(extracted);
          questionsToUse = extracted;
        }
      } catch (extractErr: any) {
        console.warn('Auto-extraction fallback to raw text:', extractErr);
      }
    }

    const exam = await generateStep3Exam(
      genState.specs,
      finalQuestionConfig,
      inputData,
      referenceDoc?.text,
      referenceDoc?.images,
      questionsToUse.length > 0 ? questionsToUse : undefined
    );
    setGenState(prev => ({ ...prev, exam, isLoading: false }));
    setCurrentStep(AppStep.EXAM);
    setCompletedSteps(Math.max(completedSteps, 3));
  } catch (err: any) {
    setGenState(prev => ({ ...prev, isLoading: false, error: err.message }));
  }
};
```

### Sự khác biệt cốt lõi để đạt chuẩn Ảnh 2:
1. **Bỏ toàn bộ đường kẻ dọc bên trong**: Bảng biến thiên chuẩn chỉ có khung viền ngoài, 1 đường kẻ dọc phân cách cột nhãn ($x, y', y$) và các đường kẻ ngang phân cách hàng. Giữa các giá trị số **hoàn toàn không có vách ngăn dọc**.

### Khi xuất sang file Word (`App.tsx`):
Trong `handleDownloadWord` của `App.tsx`, đảm bảo đoạn CSS chèn vào Word giữ nguyên các class này:

```css
<style>
  .bbt-table { border-collapse: collapse; margin: 12pt auto; border: 1px solid #000; }
  .bbt-table td { padding: 4pt 8pt; text-align: center; vertical-align: middle; border: none; }
  .bbt-table .label-col { font-weight: bold; font-style: italic; border-right: 1px solid #000; width: 40pt; }
  .bbt-table .row-border { border-bottom: 1px solid #000; }
</style>
```

Khi áp dụng thay đổi này, AI sẽ ngừng sinh các bảng ô vuông kiểu lưới ô cờ (Ảnh 1) và chuyển hoàn toàn sang bảng biến thiên chuẩn sư phạm với mũi tên nâng cao/hạ thấp mềm mại như trong sách giáo khoa và các đề thi chính thức (Ảnh 2).
